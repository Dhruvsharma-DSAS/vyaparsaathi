# VyaparSaathi City

Plan a small business in Bengaluru or Pune: market gaps on a live map, rush hours, costs and break-even, loan schemes, permits, a 7-day pilot khata and a lender pitch sheet. Five languages, accounts or guest mode, installable on phones.

- `vyaparsaathi-ui/`: Next.js web app with a Prisma (PostgreSQL) database. See its [README](vyaparsaathi-ui/README.md).
- `vyaparsaathi-ai/`: FastAPI service for the Saathi chat and calculations.

Deploy: database on Prisma Postgres, API on Render, web app on Vercel. Step by step in [DEPLOY.md](DEPLOY.md).
